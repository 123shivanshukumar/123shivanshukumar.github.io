# Useful Resources

This page contains a curated list of useful links, tools, articles, and other resources I find valuable.

## Web Development

* [MDN Web Docs](https://developer.mozilla.org/) - Comprehensive documentation for web standards and technologies.
* [CSS-Tricks](https://css-tricks.com/) - Articles and tutorials on CSS and front-end development.
* [Can I Use](https://caniuse.com/) - Browser compatibility tables for modern web technologies.
* [Web.dev](https://web.dev/) - Guidance for modern web development from Google.

## Zola & Static Sites

* [Zola Documentation](https://www.getzola.org/documentation/getting-started/overview/) - Official Zola docs.
* [Jamstack.org](https://jamstack.org/) - Information about the Jamstack architecture.
* [Static Site Generators](https://jamstack.org/generators/) - Comprehensive list of static site generators.
* [Netlify](https://www.netlify.com/) - Platform for deploying static sites with CI/CD.

## Design Resources

* [Unsplash](https://unsplash.com/) - Free high-quality stock photos.
* [Coolors](https://coolors.co/) - Color scheme generator.
* [Font Pair](https://fontpair.co/) - Helps find complementary font pairings.
* [SVG Repo](https://www.svgrepo.com/) - Free SVG vectors and icons.

## Learning Resources

* [freeCodeCamp](https://www.freecodecamp.org/) - Free coding courses covering many topics.
* [Coursera](https://www.coursera.org/) - Online courses from top universities.
* [Khan Academy](https://www.khanacademy.org/) - Free educational content on various subjects.
* [Project Euler](https://projecteuler.net/) - Mathematical and computational problems.

## Productivity Tools

* [Notion](https://www.notion.so/) - All-in-one workspace for notes, tasks, wikis, and databases.
* [Obsidian](https://obsidian.md/) - Knowledge base that works on local Markdown files.
* [Todoist](https://todoist.com/) - Task management tool.
* [Figma](https://www.figma.com/) - Design and prototyping tool.

## Books I Recommend

* **Deep Work** by Cal Newport - On the value of focused, distraction-free work.
* **Atomic Habits** by James Clear - Small changes, remarkable results.
* **The Pragmatic Programmer** by Andrew Hunt and David Thomas - Essential software development wisdom.
* **Design Patterns** by the Gang of Four - Classic text on software design patterns.
